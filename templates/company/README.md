# Company Research Workspace

This directory is the persistent research state for one covered company.

- `state/` contains the research ledger, assumptions, contradictions, and dependencies.
- `sources/` contains the source registry and reusable extracts/references.
- `data/` contains normalized tabular inputs and model outputs.
- `analysis/` contains modular analytical notes.
- `outputs/` contains user-facing publications.

Do not store the only copy of a material fact inside an output report.
