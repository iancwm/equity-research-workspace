# Company Research Workspace

This directory is durable research state for one company.

- `project.json` identifies the company and workspace schema.
- `state/` stores context, ledger records, assumptions, contradictions, and dependencies.
- `sources/` stores the source registry and reusable extracts.
- `data/` stores normalized tabular inputs and model outputs.
- `analysis/` stores editable analytical-node outputs.
- `outputs/` stores regenerated publications.

Run the bundled `validate_workspace.py` before publishing from this state.
