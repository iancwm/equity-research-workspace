# Workflow — Publish / Edit

Use when research state is already valid and the user primarily wants a report, document, spreadsheet, deck, or local section edit.

## Rules

- Read validated state rather than reconstructing research from conversation history.
- Treat Markdown as canonical text storage if convenient, but not as the only user-facing format.
- Keep each major report section independently editable.
- A wording-only edit should not alter ledger state.
- A substantive analytical edit should update ledger/assumptions first, then regenerate affected publication sections.

## IOC structure

1. Investment Thesis
2. Company Overview
3. Industry & Competitive Landscape
4. Financial Analysis
5. Forecasts & Key Assumptions
6. Valuation
7. Catalysts
8. Risks
9. Conclusion / Recommendation

## Additional surfaces

Prefer dedicated artifacts when useful:

- dashboard for monitoring;
- spreadsheet for historicals, forecasts, comps, DCF, sensitivities;
- document/PDF for distribution;
- slides for investment committee or client presentation;
- source appendix for auditability.
