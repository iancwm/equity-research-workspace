# Workflow — Full Initiation

Use for new coverage or when no reliable state exists.

## Sequence

1. Initialize the company workspace outside the skill directory.
2. Resolve research context.
3. Give preliminary framing to user.
4. Apply [source ingestion](source-ingestion.md) and [evidence normalization](evidence-normalization.md); normalize historical company data.
5. Run [Economic Engine](module-01-economic-engine.md) and persist its ledger records.
6. Run [Macro Transmission](module-02-macro-transmission.md) using relevant economic-engine state.
7. Run [Value Chain & Pricing Power](module-03-value-chain-pricing-power.md).
8. Run [Cycle vs Structure](module-04-cycle-vs-structure.md).
9. Run [Company Overlay](module-07-company-overlay.md) and forecasts.
10. Run [Valuation & Expectations](module-05-valuation-expectations.md).
11. Run the [Strategist Dashboard](module-06-strategist-dashboard.md).
12. Apply [final synthesis](final-synthesis.md).
13. Apply [QA review](qa-review.md).
14. Correct failed nodes and downstream synthesis only.
15. Publish requested outputs.

## Default outputs

- `outputs/dashboard.md`
- `outputs/initiation-of-coverage.md`

Optional:

- financial workbook;
- presentation;
- source appendix;
- scenario note.
