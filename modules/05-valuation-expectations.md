# Module 5 — Valuation & Expectations

Determine the economically appropriate valuation framework and what expectations are embedded in the current price.

## Analyze

1. Evaluate relevant metrics: P/E, EV/EBITDA, EV/EBIT, EV/Sales, P/B, P/TBV, P/FFO, NAV, FCF yield, dividend yield, replacement value.
2. Through-cycle history: current, 5-year median, 10-year median, cycle peak/trough where available.
3. Normalize earnings for cyclical businesses.
4. Peer benchmark growth, margins, FCF, ROIC, leverage, valuation, and premium/discount.
5. Do not equate a low multiple with undervaluation.
6. Private-market/replacement-value test where economically meaningful.
7. Reverse valuation: infer revenue CAGR, normalized margins, ROIC, terminal growth, and capital intensity implied by price.
8. Classify expectations: Demanding / Reasonable / Depressed.
9. Build Bear / Base / Bull cases varying the true earnings drivers and valuation assumptions.
10. Identify the variable with the largest valuation delta.
