# Workflow — Full Initiation

Use for new coverage or when no reliable state exists.

## Sequence

1. Initialize company workspace.
2. Resolve research context.
3. Give preliminary framing to user.
4. Build source registry and normalize historical company data.
5. Run Module 1 → persist ledger.
6. Run Module 2 using relevant Module 1 ledger state.
7. Run Module 3 using relevant prior ledger state.
8. Run Module 4.
9. Run Module 7 company overlay and forecasts.
10. Run Module 5 valuation & expectations.
11. Run Module 6 strategist dashboard.
12. Run final synthesis.
13. Run independent QA.
14. Correct failed nodes and downstream synthesis only.
15. Publish requested outputs.

## Default outputs

- `outputs/dashboard.md`
- `outputs/initiation-of-coverage.md`

Optional:

- financial workbook;
- presentation;
- source appendix;
- scenario note.
