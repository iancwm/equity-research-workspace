# Work-mode operating model

Use an agentic Work environment for the heavy execution path when available:

- multi-step browsing and filing retrieval;
- file inspection and persistence;
- building or updating the financial model;
- maintaining structured research state;
- selective recomputation;
- producing multiple artifacts.

Use normal chat for:

- target definition;
- investor debate framing;
- steering the research;
- challenging assumptions;
- reviewing contradictions;
- narrow edits to completed sections.

This separation reduces the "one prompt, long wait, one Markdown answer" failure mode.
